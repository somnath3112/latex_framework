**Objective:**  Create manuscript quickly with extra descriptions (key questions and bullet-point descriptions for each paragraph) that can be hidden easily.

**Link:**  [Overleaf](https://www.overleaf.com/read/ckfrcjxfmdhc#78146a).

**Details:**
- Separate files/section/chapter can build separately (fast compilation, useful in Overleaf). 
- Individual chapter build provides separate title and list of references. In full-build the title is different and references doesn't print.  
- Most needed libraries included as comment.
- Single boolean variable to switch on/off the paragraph descriptions.
- Another boolean variable to convert the manuscript into a bullet point format for planning drafts.

**Language:**  LaTeX
